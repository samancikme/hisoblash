# hisoblash — Tuwındı Esaplaǵısh / Hosila Hisoblagich

Istalgan funksiyaning $n$-tartibli hosilasini qadamma-qadam hisoblovchi zamonaviy veb-ilova.

Qálegen funktsiyanıń $n$-tártipli tuwındısın qádembe-qádem esaplaytuǵın zamanagóy veb-qosımsha.

## Imkoniyatlar / Múmkinshilikler
- 🔢 **$n$-tartibli hosila**: Darajali, ko‘rsatkichli, trigonometrik, logarifmik va murakkab funksiyalarni umumiy $n$ bo‘yicha tahlil qilish.
- 🌐 **Ko‘p tillilik**: Qaraqalpaqsha (Qoraqalpoq tili), O‘zbekcha va Ruscha.
- ⚡ **Tezkor KaTeX**: Matematik formulalarni kechikishlarsiz chizish.
- 📐 **Formulalar jadvali**: Standart $n$-tartibli hosila formulalari to‘plami.
- 💡 **Amaliy misollar**: Bitta bosish bilan yechimni ko‘rsatuvchi tayyor namunalar.
- 🌓 **Neumorphism dizayn**: Tungi va kunduzgi rejim (Dark / Light mode).
- 📋 **LaTeX nusxalash**: Natijalarni bir bosishda LaTeX formatida nusxalash.

## O‘rnatish va ishga tushirish / Ornatıw hám iske túsiriw

```bash
# Bog‘liqliklarni o‘rnatish
npm install

# Mahalliy serverni ishga tushirish (Dev)
npm run dev

# Ishlab chiqarish uchun yig‘ish (Production build)
npm run build

# Natijani ko‘rish (Preview)
npm run preview
```

## Vercel orqali deploy qilish
Loyiha Vercel uchun to‘liq tayyorlangan (`vercel.json`, `vite.config.js`). GitHub omborini Vercel'ga ulash kifoya.
